About

Offline-First Neural Intelligence for Real-Time Catch Analysis

Project Overview

An offline-first Android app using on-device neural models to help fishermen instantly identify species, assess freshness, and estimate size from a single photo. Scans are geotagged offline and auto-synced when connected, making it ideal for remote fishing zones where cloud access is unreliable.
